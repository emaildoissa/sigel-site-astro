# Keyword Mapping — Sigel Informática

## Metodologia
- **Intenção de compra (buying intent)** priorizada sobre volume de busca
- Uma keyword primária por URL
- Todas as URLs existentes mapeadas; canibalização verificada

| URL | Keyword Primária | Search Intent | Observações |
|-----|-----------------|---------------|-------------|
| `/` | criação de sites porto alegre | Comercial (comparação) | Hub principal, sem canibalização |
| `/web` | desenvolvimento web porto alegre | Comercial (contratação) | Foco em PMEs |
| `/copywriting` | copywriting estratégico porto alegre | Comercial (contratação) | Serviço complementar ao web |
| `/automacao` | automação de processos porto alegre | Comercial (contratação) | IA + WhatsApp |
| `/servicos` | serviços de ti porto alegre | Comercial (visão geral) | Landing de navegação, sem canibalização com as específicas |
| `/servicos/hardware` | manutenção de notebook porto alegre | Transacional (urgente) | Ticket baixo, volume alto |
| `/planos` | preços criação de site porto alegre | Comercial (orçamento) | Intenção de fundo de funil |
| `/sobre` | agência de ti porto alegre | Informativa (conhecimento) | Marca + credibilidade |
| `/contato` | contato sigel informática | Transacional (ação) | Conversão direta |
| `/blog` | blog criação de sites porto alegre | Informativa (educação) | Autoridade |
| `/blog/[slug]` | quanto custa criar site porto alegre | Informativa (pesquisa de preço) | Fundo de funil informativo |
| `/locais/porto-alegre` | sigel porto alegre | Comercial (local) | SEO local |

## Riscos de Canibalização Identificados

| URLs Concorrentes | Risco | Ação |
|-------------------|-------|------|
| `/` vs `/web` vs `/servicos` | Baixo | Home é hub; `/web` é serviço específico; `/servicos` é visão geral |
| `/planos` vs `/blog/[slug]` (preços) | Baixo | `/planos` é sobre processos; blog post é conteúdo informativo com tabela de preços |
